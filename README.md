# TTG Ops — sample preview (fictional data only)

A separate, static preview of the TTG Ops screens for visual review. Every person, note and invoice here is made up.
It has no backend: it never asks for a key, never connects to the real app, stores nothing, and has no service worker.
Anything you change (notes, flags, sign-offs, report drafts) stays in the open tab and is gone on reload; nothing is saved or sent.

Not the real app, and not a deployment of it. Tests: `node tests/preview.test.mjs`.
